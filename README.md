## About

The site is where I document:

* Penetration testing and CTF writeups
* Cybersecurity projects and homelab work
* Technical notes and research
* Practical security cheat sheets
* Things I learn while developing my cybersecurity skills

The content assumes basic IT and cybersecurity knowledge. I focus on documenting my methodology, experiments, failures, and lessons learned rather than explaining common tools and concepts from scratch.
